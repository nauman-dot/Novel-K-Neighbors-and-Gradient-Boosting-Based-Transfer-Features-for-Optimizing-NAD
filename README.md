# Reproducible Analysis Code

This repository contains the source code used to perform the analyses, statistical modeling, visualization, and experiments reported in the manuscript:

**“Novel K-Neighbors and Gradient Boosting Based Transfer Features for Optimizing Network Attack Detection”**

The primary objective of this repository is to support **transparency, reproducibility, and independent verification** of the reported results. The provided scripts and resources cover the complete experimental workflow, including:

* Data preprocessing and preparation
* Exploratory and statistical analysis
* Feature engineering and transfer-feature generation
* Machine learning model development
* Model training and evaluation
* Performance comparison and statistical analysis
* Visualization and figure generation
* Generation of tables and reported experimental results

Researchers can use the provided code to reproduce the main experimental results, figures, and tables presented in the manuscript.

## Data Availability

The dataset used in this study is publicly available as a downloadable release asset through GitHub.

**Dataset Download:** GitHub Releases

Please download the required dataset from the repository's **Releases** section and place the files in the directory specified by the data-loading scripts before running the experiments.

## Reproducibility

To reproduce the reported experiments:

1. Clone or download this repository.
2. Download the dataset from the GitHub Releases section.
3. Install the required Python dependencies.
4. Configure the dataset path according to the provided scripts.
5. Run the preprocessing and feature-engineering scripts.
6. Execute the model-training and evaluation scripts.
7. Run the visualization and statistical-analysis scripts to generate the corresponding figures and tables.

The repository is organized to allow the experimental workflow to be followed from data preparation through final evaluation and visualization.
